---
description: QA-гейт на текущих изменениях — lint + sanity + один полный прогон coverage:changed (он же npm test) через .claude/scripts/qa-gate.sh. При RED — разбор агентом qa-e2e по логу.
argument-hint: [база сравнения, по умолчанию main]
allowed-tools: Task, Read, Bash
---

1. Запусти `bash .claude/scripts/qa-gate.sh $ARGUMENTS` (без аргумента база — `main`). Скрипт сам
   различает нерантайм-изменения (`npm test: N/A`) и сам оборачивает прогон в `xvfb-run` без дисплея.
2. **GREEN** — верни сводку гейта как есть.
3. **RED** — если причина очевидна из сводки (непокрытая ветка, падение нового теста задачи), назови её
   и кому вернуть. Если неочевидна — делегируй агенту `qa-e2e` разбор `out/qa-gate.log` (полный прогон
   он не повторяет) и верни его отчёт.

`reviewer` после гейта запускается отдельно командой `/review`.
